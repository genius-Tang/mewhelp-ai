# MewHelp AI 项目

这是一个按章节逐步开发的电商智能客服项目。每章使用独立目录保存代码、测试、运行说明和开发记录，便于从任意章节查看当时的完整实现。

## 章节目录

| 章节 | 内容 | 入口 |
| --- | --- | --- |
| Chapter 01 | 纯对话、SSE 流式输出、多轮上下文、售后结构化提取、Web 聊天页面 | [ch01-pure-chat](./ch01-pure-chat/) |
| Chapter 02 | 工具调用、MySQL 会话持久化、订单与物流、商品、FAQ 和人工工单 | [ch02-function-calling](./ch02-function-calling/) |

进入对应章节目录后，按照该目录的 README 创建环境并运行。
